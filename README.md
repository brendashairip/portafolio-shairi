# Portafolio — Shairi Pineda

Portafolio UX/UI · Product Designer. Sitio estático (HTML/CSS/JS, sin dependencias).

## Ver localmente
Abre `index.html` en el navegador (doble clic).

## Publicado en Vercel
Conectado a este repo: cada `git push` publica los cambios automáticamente.

## Estructura
- `index.html` — el sitio completo (Inicio, Case study, Sobre mí, Contacto, Sistema)
- `img/` — imágenes

## Actualizar el sitio
1. Reemplaza archivos (por ejemplo imágenes en `img/`, con el mismo nombre).
2. Sube los cambios:
   ```bash
   git add -A
   git commit -m "actualizo imágenes/textos"
   git push
   ```
3. Vercel vuelve a publicar solo en unos segundos.
